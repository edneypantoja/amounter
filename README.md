# Amounter

**Amounter** é uma aplicação web de cálculos financeiros, desenvolvida com HTML, CSS e JavaScript.

O projeto tem como objetivo disponibilizar ferramentas de cálculo financeiro de forma simples, rápida e acessível diretamente pelo navegador.

## 🚀 Acesso

A aplicação pode ser utilizada diretamente pelo navegador através do GitHub Pages.

## 🧮 Funcionalidades

O projeto reúne ferramentas voltadas para cálculos e análises financeiras, com uma interface simples e sem necessidade de instalação.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## 📁 Estrutura

```text
amounter/
├── Pages/
├── assets/
│   └── ads/
├── compliance/
├── css/
├── images/
└── index.html
```

## 🎯 Objetivo

O Amounter é um projeto independente desenvolvido para transformar cálculos financeiros em ferramentas web práticas e fáceis de utilizar.
